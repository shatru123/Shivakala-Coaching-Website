3. End-to-End Journeys

Admission-to-Portal Flow

1. Visitor registersUses public Registration form or admin manually adds the student.
→
2. Admin reviewsFilters, updates student status, adds notes, exports CSV if needed.
→
3. Student admittedStudent can be assigned to a batch and connected to fees, attendance, exams.
→
4. Parent portal worksLinked mobile / student account can view attendance, fees, and results.

Academic Management Flow

1. Admin creates structureAdds teachers, batches, timetable, exams, fee structure.
→
2. Teacher executesMarks attendance, posts homework, enters marks.
→
3. Admin publishes and monitorsReviews records, prints receipts, publishes exams, audits changes.
→
4. Parent monitorsViews attendance, fees, and exam results in portal.

  • Admin logs in with username and password.
  • Authenticated admin sees an admin bar and dashboard shortcuts.

5.3 Registrations

/admin/registrations

  • Shows all submitted admission forms.
  • Filter by status and search by name/mobile.
  • Update student status using modal workflow.
  • Add optional admin notes.
  • Export all registrations as CSV.
  • Manually add a student through Add Student.

5.4 Teachers

/admin/teachers

  • Add, edit, and delete teachers.
  • Manage teacher profile data: full name, code, mobile, email, qualification, specialization, address, salary, joining date, photo, notes.
  • Create teacher portal credentials with custom username/password or allow generated defaults.
  • Mark teacher as active/inactive.

5.5 Portal Accounts & Password Management

/admin/portalaccounts

  • Lists teacher and parent portal accounts.
  • Shows linked person, username, mobile, status, and role.
  • Admin can reset password for teacher and parent accounts.
  • Admin can also change their own password separately.

5.6 Batches

/admin/batches

  • Create batches with name, standard, medium, timing, room, max strength, academic year, and active flag.
  • Open batch detail page to add/remove students.
  • Jump from a batch into attendance marking, timetable view, and attendance reports.

5.7 Attendance

/admin/attendance

  • Select batch and date to open attendance sheet.
  • Mark each student Present / Absent / Leave using radio buttons.
  • Use Mark All Present or Mark All Absent shortcuts.
  • Save attendance for the selected date.
  • Run reports by student or batch with from/to date range.

5.8 Timetable

/admin/timetable

  • Select a batch and view the weekly timetable grid.
  • Add timetable slots with subject, teacher, day, start time, end time, and room.
  • Conflict detection prevents overlapping timetable slots for the same teacher on the same day/time window.
  • Delete timetable slots from the grid.

5.9 Exams

/admin/exams

  • Schedule exams with title, standard, subject, type, optional batch, total marks, passing marks, duration, and exam date.
  • Open marks entry for each exam.
  • Save marks student-wise and recalculate ranks.
  • Publish exams/results when ready.
  • Delete exams if needed.

5.10 Homework

/admin/homework

  • Create homework manually from admin.
  • Fields include title, subject, standard, teacher, optional batch, due date, attachment, and description.
  • View homework list and attachments.
  • Open submission view for a homework item.
  • Delete homework records.

5.11 Fees

/admin/fees

  • Filter fee records by month and status.
  • Collect a fee with student, fee type, month, amount, discount, fine, net payable, payment mode, reference, date, and remarks.
  • Auto-calculates the effective payable amount.
  • Print receipt after collection.
  • Maintain fee structure separately by standard, fee type, amount, and academic year.

5.12 Notices

/admin/notices

  • Create and edit bilingual notices.
  • Fields: English title/body, Marathi title/body, category, published date, pinned, active.
  • Delete notices.

5.13 Test Results (Weekly Result Module)

/admin/results

  • Add weekly test style result entries manually.
  • Fields include test title, student name, standard, subject, score, total marks, rank, test date, and remarks.
  • Delete result entries from the list.

5.14 Study Materials

/admin/materials

  • Upload files such as PDFs, docs, and images.
  • Fields include title, Marathi title, material type, standard, subject, active flag, and file.
  • Preview/download uploaded material.
  • Delete material records.

5.15 Courses

/admin/courses

  • Create, edit, and delete courses displayed on the website.
  • Manage title, slug, bilingual descriptions, standard, duration, display order, and featured flag.

5.16 Gallery

/admin/gallery

  • Upload gallery items with title, category, caption, and image file.
  • Delete gallery images.
  • Supports categories like General, Event, Results, Classroom, and Achievement.

5.17 Testimonials

/admin/testimonials

  • Create testimonials directly or manage user-submitted testimonials.
  • Edit name, role, English quote, Marathi quote, rating, approval, and featured status.
  • Quick actions: Approve and Approve + Feature.
  • Delete testimonials.

5.18 Homepage Content

/admin/homepagecontent

  • Show/hide statistics section on homepage.
  • Edit all 4 statistic values and their English/Marathi labels.
  • Show/hide testimonials section on homepage.
  • Edit testimonial eyebrow/title text in English and Marathi.
  • Use Testimonials page to control which cards are visible and featured.

5.19 WhatsApp Broadcast

/admin/whatsapp

  • Authenticate WhatsApp by scanning QR code from the sidecar service.
  • Send broadcast to all parents or a specific batch.
  • Use quick templates to prefill common messages.
  • Review broadcast log with date, message, audience, sent count, failed count, and status.
Operational note: WhatsApp broadcasting depends on the WhatsApp sidecar being available and authenticated.

5.20 Audit Log

/admin/auditlog

  • View paginated activity records with date/time, action, entity, record ID, performer, and IP address.

6. Teacher Portal Guide

The teacher portal is focused on classroom execution rather than institute administration.

/teacher/login
/teacher
Teacher Dashboard
Shows assigned batches, homework and exam counts, and quick action links.
Teacher Attendance Screen
Daily attendance workflow with batch selection and save action.

6.1 Login

  • Teacher logs in with assigned portal credentials.
  • Session shows teacher portal bar at the top.
  • Teacher can log out anytime.

6.2 Dashboard

  • Shows teacher identity and assigned batches.
  • Key counts: my batches, active homework, total homework, upcoming exams, total students.
  • Provides quick actions to attendance, homework, and exam marks.

6.3 Attendance

/teacher/attendance

  • Select one of the teacher’s assigned batches.
  • Choose date.
  • Mark status for each student in the batch.
  • Save attendance for the selected day.

6.4 Homework

/teacher/homework

  • See homework previously assigned by that teacher.
  • Create new homework with title, subject, standard, optional batch, due date, description, and attachment.
  • Delete homework created by the same teacher.

6.5 Exams & Marks

/teacher/exams /teacher/exams/{id}/marks

  • View scheduled exams relevant to classroom work.
  • Open a specific exam’s marks page.
  • Enter marks student-wise, with support for absent entries.
  • Save marks back to the system.

6.6 Change Password

/teacher/change-password

  • Teacher enters current password, new password, and confirmation.
  • Updates own password without admin help.
Teachers are intentionally restricted to teacher workflows only. They should not be using admin screens.

7. Parent Portal Guide

The parent portal is a view-first portal for tracking the child’s status.

/parent/login
/parent
Parent Dashboard
Single place for attendance, fee, and result visibility for linked children.

7.1 Login

  • Parent logs in using the linked portal account.
  • Credentials are typically tied to the student/parent mobile record.
  • Successful login opens the parent dashboard.

7.2 Dashboard

  • Supports one or multiple linked children under the same parent mobile.
  • Shows recent attendance, recent fee records, and recent exam results.
  • Highlights relevant child data in one place.

7.5 Exam Results

  • Recent exam results are visible directly on the parent dashboard.
  • Includes exam name and marks/grade when available.

/parent/change-password

  • Parent can update their own portal password securely.

11. FAQ & Notes

Can admin manage whether homepage stats/testimonials appear?

Yes. The Homepage Content screen controls visibility and text.

Can teachers access admin pages?

No. Admin areas are role-restricted. Teachers use only the teacher portal.

Can parents change their own password?

Yes. Parent portal includes a self-service change password screen.

Can admin reset teacher and parent passwords?

Yes. Use Portal Accounts to reset them.

How are admission leads handled?

They enter through Registration or manual admin creation, then move through status updates in Registrations.

How are testimonials published?

User testimonials are submitted publicly, then approved by admin before becoming visible.

How do WhatsApp broadcasts work?

Admin authenticates WhatsApp using QR, then sends to all parents or a chosen batch. Delivery is logged.

Important operating habit: for parent portal visibility to work smoothly, the student record should have the correct parent mobile / linked portal account information.
